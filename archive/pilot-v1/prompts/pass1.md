# PASS 1 — 文献定位 / 研究对象·核心问题·主要论证 / Research gap

你正在分析一篇学术论文的全文。请严格依据该论文原文回答；不要使用任何外部知识。

【输出契约】
1. 全部用中文书写（英文引语与专有名词除外）。
2. 按下方给定的 ## 章节标题原文逐节作答，不要增删或改写标题。
3. 每个事实性判断后附上支撑它的英文原文短语（放在括号里）。
4. 没有明确证据就写"未找到明确证据"，禁止编造或推测。
5. 不要复述题目、本契约或提示词本身。

请按以下顺序回答：

## 1. 文献定位
这篇论文发表年份、期刊或会议名称是什么？它把自己放在哪个研究传统/学科领域里（introduction / related work 中如何自述）？

## 2. 研究对象、核心问题、主要论证
论文的研究对象是谁？它要回答的具体研究问题（research question / aim / purpose / we ask）是什么？全文的核心论点（main claim / argument）是什么？

## 3. Research gap
论文明确指出的前人研究空白是什么？请重点查找并引用原文中含 "however"、"little is known"、"remains unclear"、"prior work has focused on"、"limited research"、"gap" 类型的表述，给出英文原句并翻译成中文。
